# 使用说明

## 准备游戏

ZIP 应包含完整、可信的 Windows 游戏目录。可以把目录本身作为 ZIP 的顶层，也可以直接压入其内容。保留相对目录结构，补丁入口可在子目录内选择。默认读取 UTF-8 ZIP；老中文压缩包若出现乱码，在「运行环境 → ZIP 文件名编码」选 GBK 后重新导入。

普通 ZIP 不需要专用清单。一次导入产生独立目录，重复标题不会覆盖已有游戏。导入失败时清理本次临时目录，已有游戏和存档不受影响。无法自动下载游戏或绕过游戏原有授权验证。

## 图标与启动

点图标开始游戏。长按卡片或点「管理」打开菜单：选择启动 EXE、重命名、选择 PNG/JPEG 等系统支持的图片，或添加安卓桌面入口。EXE 会从游戏目录递归列出。改名称仅改图标名称，不改资源文件名。

默认工作目录是 EXE 所在目录。某些汉化启动程序在子目录中，而资源由游戏根目录提供，需要在「游戏运行设置」选择游戏根目录。运行时使用 L: 指向 EXE 所在目录，M: 指向游戏根目录。Unicode 启动助手通过 Windows 宽字符接口保留中文、日文 EXE 名称。

存量 Study Steady 导入目录在升级到游戏库时原地登记；不搬动资源或保存路径。旧版本已经转换过的拼音目录仍可选择。

## 输入

直接点击画面发送鼠标左键。边缘「继续」发送左键，「菜单」发送右键，「隐藏」发送空格，「快进」切换按住左 Ctrl，「返回」发送 Esc。具体按键含义取决于游戏；高级设置可编辑控制布局。按键布局可在每款游戏设置里关闭。

安卓系统返回键打开运行环境菜单；运行菜单 Exit 关闭环境。需要更准确的窗口点击时关闭全屏缩放。四指触摸也可打开运行菜单，双指操作见运行菜单 Touchpad Help。

## 保存与备份

SAVE / LOAD 由原游戏处理。游戏目录、Wine 用户目录和注册表保存在应用私有存储中，下次启动复用。保存后通过运行菜单 Exit 关闭环境，再导出或恢复备份，避免读取游戏正在写入的文件。

备份导出是带 SHA-256 清单的 ZIP，恢复先验证全部文件再提交，并保留恢复前的数据。覆盖范围：

- `.wine/drive_c/users` 的真实文件，跳过指向外部目录的符号链接。
- Wine 的 user.reg、system.reg、userdef.reg。
- 游戏目录任意层级的 save、saves、savedata。
- 新导入游戏中不超过 16 MiB 的 dat、ini、sav、save、ksd、asd、rms 文件。

大型资源不属于存档备份。特别是游戏将进度写到自定义位置、其它盘符或特殊扩展名时，不能假定这份备份已完整覆盖。高级环境中可以手动复制额外位置。

备份不包含游戏库索引或完整游戏。新安装的应用需要先重新导入原游戏；目前跨设备迁移新导入游戏的随机目录需要手动匹配保存路径。可靠覆盖升级和同一环境的备份恢复是当前版本的目标，完整跨设备库迁移列入后续计划。

卸载、清除应用数据会删除内部数据；关闭环境、重启设备和同签名覆盖升级会保留。移除图标不会释放游戏占用空间，也不会删除进度。保留的目录可通过高级环境访问。
