# 性能与兼容性

当前设备实测基准是小米 Pad 6 Pro，Snapdragon 8+ Gen 1 / Adreno 730，Android 15。已知事实和测试范围见 [VALIDATION](../VALIDATION.md)。

## 调整顺序

1. 用「运行环境 → 性能与图形」开启 FPS，记录同一段动态画面的刷新与响应。
2. 尝试 CPU 性能优先；有崩溃、声音或演出异常时回到均衡或稳定优先。每款游戏可以覆盖公共 CPU 预设。
3. Adreno 设备可尝试 Turnip + Zink + DXVK；其它设备保留 Vortek + Gladio，旧游戏可测试 VirGL + WineD3D。驱动切换影响同一环境里的全部游戏。
4. 比较 1280×720 与 960×540。低分辨率能降低渲染负载，但文字也会变粗。不要同时改变多个设置再归因。
5. 日常关闭调试日志；保留运行环境的 shader cache。高级设置可更换可用驱动、DXVK 和 Box64 组件版本。

不强制修改 Android 温控、CPU 调频、系统服务或设备上的其它应用。开启高性能预设不等于已经获得某个 FPS 提升；游戏可能受单线程逻辑、视频解码、引擎帧率上限或图形转换影响。

FPS 浮层统计游戏窗口内容更新，静止菜单会降低更新率。比较时应在同一动态场景、相同分辨率、相同温度条件下至少观察 60 秒，同时检查音频和点击响应。

## 兼容性边界

这是 Windows 运行兼容方案，基于 Wine 和 Box64；没有为每个 Galgame 引擎重写原生 Android 解释器。不同引擎的插件、视频格式、日语编码、DirectDraw / Direct3D 版本、运行库、授权验证等仍可能影响结果。

[Winlator 上游使用建议](https://github.com/brunodev85/winlator#useful-tips) 包含 CPU 稳定预设、旧 OpenGL 扩展与音频延迟等处理方式。新游戏先用可验证的最小配置测试，成功后通过兼容性 issue 分享设置。

报告可玩时，请分别标明：标题、剧情、字体、触控、音频、视频、保存、环境关闭后重启读档和长时稳定性。只进入标题不能作为完整可玩的证明。
